# HSG_financial_analysis

## 📌 Executive Summary
A comprehensive financial evaluation of Hoa Sen Group (HSG) during its strategic transition from pure manufacturing to a distribution and retail ecosystem (Hoa Sen Home). Using advanced DuPont Decomposition and capital efficiency metrics, the analysis evaluates profitability drivers and value creation against industry peers and HSG's Weighted Average Cost of Capital (WACC).

## 🛠️ Tech Stack & Tools
- **Analysis Tool:** Microsoft Excel
- **Financial Frameworks:** Advanced DuPont Decomposition (ROA, ROCE, ROE), Peer Benchmarking, WACC Spread Analysis

## 📂 Project Structure
├── models/             # Excel financial model (2022–2024 balance sheets, P&L, DuPont tree)
├── reports/            # Comparative analysis vs. Nam Kim and Hoa Phat Group
└── README.md           # Project documentation

## 🚀 Key Results & Findings
- **Operational Recovery:** ROA recovered from **0.23% to 2.75%**, driven by gross margin expansion and higher asset utilization.
- **Capital Allocation Gap:** Return on Capital Employed (ROCE) consistently lagged behind WACC, showing that economic value creation remains constrained.
- **Strategy Validation:** The "Asset-light" retail expansion improved operational efficiency but highlighted weaknesses in capital deployment.

## 💼 Business Impact & Recommendations
- **Capital Allocation:** Reallocate capital to higher-yield assets to close the ROCE-WACC gap.
- **Strategic Positioning:** Continue leveraging the Hoa Sen Home ecosystem while optimizing inventory and working capital turnover.
